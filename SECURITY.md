# Security policy

Report a suspected vulnerability using [GitHub's private reporting form](https://github.com/Rexus/SkyView/security/advisories/new).
Keep vulnerability details, credentials and sensitive model data out of public issues and pull requests.

Include the SkyView version and revision, deployment mode, what an attacker could do and how
maintainers can reproduce it. When possible, attach a sanitized build report and a minimal example
that reproduces the issue. Coordinate disclosure with the maintainers in the GitHub advisory.

Use the [public issue tracker](https://github.com/Rexus/SkyView/issues/new/choose) for ordinary bugs
and feature requests.
