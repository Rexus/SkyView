# SkyView example projects

Open **Projects → Examples** in SkyView to create an editable copy, or browse a project here.

| Example | Model and supporting material |
| --- | --- |
| [Starter system](starter/) | Small introduction to parts and connections |
| [Inspection drone](inspection-drone/) | Subsystems, requirements, mission behavior and a sequence preview |
| [Inverted pendulum](inverted-pendulum/) | Cart-and-rail model, swing-up controller and numerical simulation |

Each directory keeps its `skyview.project.json` manifest and native sources under `models/`.
Builds embed the manifest, models and project README. Optional analysis tools run from the repository.
