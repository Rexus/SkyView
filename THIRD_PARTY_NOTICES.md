## Official SysML validation toolchain

The default container and optional native-check setup include the unchanged official
SysML v2 Pilot Implementation selected in the release lock (currently 2026-04, kernel 0.59.0),
plus the matching release libraries. Build outputs contain the exact selected manifest and upstream notices.
The pilot and libraries use EPL-2.0, independently of SkyView's MIT license. The delivered JAR also
contains PlantUML 1.2022.7 in its EPL-1.0 edition (checked with the bundled `-license` command), plus
other upstream dependencies. SkyView does not invoke its diagram renderer. The JAR retains
its bundled third-party license/notice resources. Setup installs the release license and source
links in the toolchain's `licenses/` directory; retain them when redistributing the toolchain/image.
The original SkyView Java adapter is MIT licensed and communicates with the Go app through a
separate process. No Tom Sawyer SDK or branded assets are included.
